# LinkedIn et social selling : skill Claude Code

Profil qui convertit, posts qui créent des conversations, commentaires stratégiques, invitations et messages privés qui mènent à des rendez-vous.

**Ce que vous obtenez :**
- Un profil LinkedIn qui présente votre offre comme une page de vente
- Des posts et des commentaires qui ouvrent des conversations avec vos cibles
- Des messages après connexion qui mènent à des rendez-vous, sans paraître commercial

Un skill gratuit pour [Claude Code](https://claude.com/claude-code), en français, pensé pour les dirigeants de TPE et PME, les indépendants, les commerciaux et les agences.

## Installation

**macOS / Linux**
```bash
git clone https://github.com/leadforgeworks/skill-linkedin-social-selling ~/.claude/skills/linkedin-social-selling
```

**Windows (PowerShell)**
```powershell
git clone https://github.com/leadforgeworks/skill-linkedin-social-selling "$HOME.claudeskills${dir}"
```

Redémarrez Claude Code : le skill se déclenche tout seul quand votre demande correspond. Pour le mettre à jour : `git pull` dans ce dossier.

## Exemples de demandes
- « Réécris mon titre et ma section Infos LinkedIn »
- « Écris un post sur une erreur fréquente de mes clients »
- « Prépare 3 messages après acceptation d'une invitation »
